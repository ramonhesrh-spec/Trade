# Register: waar staat wat

Eén regel per bestand. Het register wijst naar de bestaande bestanden; er is niets verhuisd (docs/blueprint.md, onderdeel 5).

- besluiten: `docs/onderzoek/besluiten.md`
- hypotheses: `docs/onderzoek/hypotheses.md`
- bewijs: `docs/onderzoek/bewijsregister.md` (smoketest-uitslagen: nog niet aanwezig)
- skills: `docs/register/skills.md`
- wijzigingen van vaste waarden: `docs/register/wijzigingen-config.md`
- taken (één actieve taak): `docs/taken/NU.md`
- parkeerlijst: `docs/taken/NU.md`, kop Parkeerlijst
- leveringen: `docs/register/leveringen.md`
- voortgang en onderzoeksgeheugen: `docs/onderzoek/voortgang.md`, `docs/onderzoek/README.md`
- architectuur per onderdeel: `docs/architectuur.md`
- Gitea-stappen: `docs/gitea-stappen.md`
